# Centrum Wywiadu i Detektywistyki — wersja podglądowa

Statyczny eksport serwisu, wygenerowany z lokalnej instalacji WordPressa
(motyw blokowy `detektyw`). Służy wyłącznie do pokazania wyglądu i treści.

**To nie jest wersja produkcyjna.**

- Cały serwis ma `noindex` oraz `robots.txt` z `Disallow: /`.
- Formularz kontaktowy jest zastąpiony informacją z telefonem i adresem
  e-mail — statyczny host nie obsługuje wysyłki.
- Wyszukiwarka i kanały RSS są nieaktywne (wymagają backendu).
- Treści zawierają widoczne bloki „DO UZUPEŁNIENIA” — 27 miejsc, w których
  brakuje danych od właściciela firmy.

Docelowo serwis wymaga hostingu z PHP i MySQL.
